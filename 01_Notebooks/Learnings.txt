venv- A normal folder name for virtual environment.
venv/

.venv-Same as venv, but hidden/config-style naming.
Modern convention and preferred by VS Code.
.venv/

.env- NOT a virtual environment.
It is usually a file storing secret keys or environment variables.
Example:OPENAI_API_KEY=xyz
