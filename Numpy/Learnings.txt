# NumPy Theory

## History of NumPy

Python already had very high computational capabilities and was easy to use, but it lacked efficient array processing for scientific computing.

### Problem in Early Python

* Python lists were slow for numerical computations.
* No optimized multidimensional arrays.
* Scientific calculations required faster memory-efficient structures.

---

## Early Development

### Early 2000s — Numarray Library

A library called **Numarray** was introduced to improve numerical computing performance.

### Problems with Numarray

* Better than normal Python lists
* Still had compatibility issues
* Scientific ecosystem was fragmented

---

## 2005 — Birth of NumPy

Travis Oliphant combined:

* Numeric library
* Numarray library

to create:

# NumPy

NumPy became the standard numerical computing library for Python.

---

# Why NumPy is Fast

NumPy is mainly written in **C language** internally.

Because of this:

* Operations happen at C-level speed
* Memory usage is optimized
* Numerical computations become very fast

NumPy arrays are often:

* 20x–50x faster than Python lists
* More memory efficient

---

# Python List vs NumPy Array

| Feature                 | Python List                | NumPy Array            |
| ----------------------- | -------------------------- | ---------------------- |
| Data Types              | Multiple datatypes allowed | Usually same datatype  |
| Speed                   | Slower                     | Much faster            |
| Internal Working        | Python-level               | C-level optimized      |
| Memory Usage            | Higher                     | Lower                  |
| Vector Operations       | Manual loops required      | Built-in vectorization |
| Mathematical Operations | Difficult/slower           | Easy and fast          |
| Scientific Computing    | Not ideal                  | Best for it            |

---

# Python List Example

### Characteristics

* Can store mixed data types

# NumPy Array Example

```python id="jz0m31"
import numpy as np

arr = np.array([1,2,3,4])
```

### Characteristics

* Stores same datatype efficiently
* Faster mathematical operations
* Optimized memory storage

---

# Vector Operations

## Python List

Requires loops:

```python id="g4l7gx"
lst = [1,2,3]

result = []

for i in lst:
    result.append(i * 2)

print(result)
```

---

## NumPy Array

Direct vectorized operation:

```python id="hzsqxv"
arr = np.array([1,2,3])

print(arr * 2)
```

Output:

```python id="g1b77u"
[2 4 6]
```

This is called **vectorization**.
